# Homebrew tap for Explorer

```bash
brew install --cask preslav-panayotov/tap/explorer-macos
```

Installs [Explorer for macOS](https://github.com/preslav-panayotov/explorer-macos) — a native file manager that looks and works like Windows 11 File Explorer — plus the `explorermac` terminal command.

Upgrade: `brew upgrade --cask explorer-macos` · Remove: `brew uninstall --cask --zap explorer-macos`
